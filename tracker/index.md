# Task Index Archive

This file is a historical snapshot from the legacy `tracker/` workflow. It is not a live queue, not a source of truth, and not an operational runbook.

## Current Authority

- `.ok/project-management.ok.md` is the project-management authority.
- `.tasks/` contains live task state.
- Do not use this file to select work, update status, manage blockers, or query current priorities.

## Archived Snapshot

Legacy tracker materials once grouped work by priority and status. That information is preserved only as historical context for older references.

- The linked task files under `tracker/tasks/` are archived examples.
- Any status values shown in those files reflect past snapshots, not current execution state.
- Counts, priorities, and area summaries from the legacy tracker are intentionally not maintained.

## Historical Interpretation Notes

- If you encounter a legacy task ID in older commits or specs, use this directory only to understand the reference.
